# 弥生会計 インポートデータ作成ツール

エクセルと通帳PDFから、弥生会計（デスクトップ版）の**仕訳インポート形式CSV**を作ります。
取り込み前に人が確認すべき点を洗い出した**確認リスト**も併せて出力します。

## できること

- 通帳の取引明細から普通預金の仕訳を起こす
- 摘要・振込名義から勘定科目・補助科目・税区分を自動判定する（ルールはYAMLで編集）
- 消費税額を弥生と同じ端数処理で計算する（インボイス経過措置80%にも対応）
- 元本＋利息のような按分、源泉徴収のような複合仕訳（諸口）を組み立てる
- 通帳の印字残高との突合、貸借一致、預金増減の一致を自動で検算する

## 使い方

通帳・売上エクセル・経費精算書から、**1本のインポートCSV**を作ります。

```bash
python3 tools/build_journal.py \
    --passbook clients/<関与先>/passbook.csv clients/<関与先>/rules.yaml --opening 200551 \
    --sales    売上入力.xlsx   clients/<関与先>/rules_sales.yaml \
    --expenses 経費精算書.xlsx clients/<関与先>/rules_keihi.yaml \
    --from 2025-07-01 --to 2026-06-30 \
    --out out/仕訳日記帳.csv \
    --review out/確認リスト.md --review-docx out/確認リスト.docx
```

確認リストはMarkdownとWordの両方に出せます。Wordは確信度ごとに章を分け、
1件ずつチェックボックスを付けてあるので、そのまま回付や打合せに使えます。
（Word出力には `python-docx` が必要です）

資料は必要なものだけ渡せます。日付順に並べ替え、伝票No.を通しで振り直します。
`--opening` には期首（前期末）の預金残高を渡します。

同じ取引が通帳とエクセルの両方に載っていることがあります。二重計上を避けるため、
片方のルールに `exclude: true` を書いておくと、その取引は仕訳になりません。

### OCRした通帳PDFで転記を裏取りする

```bash
python3 tools/verify_ocr.py clients/<関与先>/passbook.csv OCR済み通帳1.pdf OCR済み通帳2.pdf
```

判定は3段階です。**未確認**はOCRがその行を拾えていないだけで、転記との矛盾ではありません。
OCRは失敗するページがあるので補助的な確認です。転記の裏取りは差引残高の連鎖が主です。

## 通帳CSVの作り方

スキャンした通帳PDFにはテキスト層がないため、読み取り結果をいったん次の形式のCSVにします。

| 列 | 内容 |
| --- | --- |
| `date` | 取引日（`YYYY-MM-DD`） |
| `kind` | `in`=お預り / `out`=お支払 |
| `summary` | 摘要欄の表示（`カード` `振込1` `為替手数料` など） |
| `counterparty` | 振込依頼人・振込先の名義 |
| `amount` | 金額 |
| `balance` | 差引残高（印字がある行だけ。**検算に使う**ので必ず入れる） |

`balance` を入れた行が検算のチェックポイントになります。1桁でも読み違えると
そこで止まるので、桁の読み間違いがそのまま帳簿に入ることはありません。

## 経費精算書を読むときの注意

関与先が手入力している経費精算書は、右端の「金額」欄が空のまま費目欄にだけ
金額が入っている行があり、合計行のO列も式が崩れていることがあります。
金額の正は費目欄（宿泊費〜その他）のほうなので、そちらから読みます。

読み取ったあと、各月シートの合計行（費目欄の合計）と突き合わせて検算します。
一致しなければ行を取りこぼしているので、生成を止めます。

## 消費税の取扱い

税区分ごとの税額は、内税の切捨てとインボイス経過措置の端数処理を弥生に合わせてあります。

少額特例（税込1万円未満の課税仕入れはインボイスの保存を要さず全額控除できる）を
使う場合は、ルールYAMLに次を書きます。基準期間の課税売上高が1億円以下、または
特定期間が5千万円以下の事業者が、令和5年10月1日から令和11年9月30日までの
課税仕入れについて適用できます。

```yaml
small_amount_special:
  apply: true
  threshold: 10000
```

これを入れると、1万円未満の課税仕入れは `deduction` の指定にかかわらず全額控除で
計算します。適用要件を満たさない関与先では `apply: false` にしてください。

また、摘要に適格請求書発行事業者の登録番号（`T` のあとに13桁）が書かれている行は、
`deduction` の指定にかかわらず適格として扱います。関与先が領収書を確認して摘要に
番号を書き足せば、そのぶんが自動で全額控除に切り替わります。止めるには
`detect_invoice_number: false` を書きます。

## 出力する弥生インポート形式

25列固定・ヘッダーなし・Shift_JIS・改行CRLF。**列の並び、引用符の付け方、日付の書式、
複合仕訳の表し方は、弥生会計から「弥生インポート形式」で書き出した実ファイル（528行）
と突き合わせて確認済み**です。

| 項目 | 仕様 |
| --- | --- |
| 取引日付 | 和暦 `R.06/07/01` |
| 引用符 | 伝票No.・金額・税額・タイプ以外を `"` で囲む |
| 税区分 | `課対仕入内10%適格` `課対仕入内10%区分80%` `課税売上内10%` など |
| 税金額 | 内税・切捨て。**仕入税額控除の割合は掛けない**（経過措置は税区分名で表す） |
| 複合仕訳 | 諸口は使わない。同じ伝票No.の連続行を `2110`→`2100`→`2101` と並べ、タイプに `3` を立てる |

複合仕訳の各行は借方・貸方を独立に持ちます。片側だけの行は反対側を空にして金額0とします。

```
"2110",136,"","R.07/09/30","支払報酬料","","","課対仕入内10%適格",165000,15000,"普通預金","三菱UFJ銀行","","対象外",149685,0,"税理士　山田俊輔","","",3,"","","0","0","no"
"2101",136,"","R.07/09/30","","","","対象外",0,0,"預り金","","","対象外",15315,0,"税理士　山田俊輔　源泉所得税","","",3,"","","0","0","no"
```

## 関与先データの取り扱い

このリポジトリは公開されています。関与先の実データ（通帳CSV・エクセル・出力CSV）は
`.gitignore` で除外してあり、コミットされません。`clients/` 配下に置いてください。
`clients/_example/` だけが匿名のひな形として追跡対象です。
