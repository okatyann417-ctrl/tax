# 弥生会計 インポートデータ作成ツール

エクセルと通帳PDFから、弥生会計（デスクトップ版）の**仕訳インポート形式CSV**を作ります。
取り込み前に人が確認すべき点を洗い出した**確認リスト**も併せて出力します。

## できること

- 通帳の取引明細から普通預金の仕訳を起こす
- 摘要・振込名義から勘定科目・補助科目・税区分を自動判定する（ルールはYAMLで編集）
- 消費税額を弥生と同じ端数処理で計算する（インボイス経過措置80%にも対応）
- 元本＋利息のような按分、源泉徴収のような複合仕訳（諸口）を組み立てる
- 通帳の印字残高との突合、貸借一致、預金増減の一致を自動で検算する

## 使い方

```bash
python3 tools/generate_passbook.py \
    clients/<関与先>/passbook.csv \
    clients/<関与先>/rules.yaml \
    --opening 200551 \
    --from 2025-07-01 --to 2026-06-30 \
    --out out/普通預金.csv \
    --review out/確認リスト.md
```

`--opening` には期首（前期末）の預金残高を渡します。これが合っていれば、
通帳に印字された差引残高との突合で転記ミスが必ず検出できます。

## 通帳CSVの作り方

スキャンした通帳PDFにはテキスト層がないため、読み取り結果をいったん次の形式のCSVにします。

| 列 | 内容 |
| --- | --- |
| `date` | 取引日（`YYYY-MM-DD`） |
| `kind` | `in`=お預り / `out`=お支払 |
| `summary` | 摘要欄の表示（`カード` `振込1` `為替手数料` など） |
| `counterparty` | 振込依頼人・振込先の名義 |
| `amount` | 金額 |
| `balance` | 差引残高（印字がある行だけ。**検算に使う**ので必ず入れる） |

`balance` を入れた行が検算のチェックポイントになります。1桁でも読み違えると
そこで止まるので、桁の読み間違いがそのまま帳簿に入ることはありません。

## 出力する弥生インポート形式

25列固定・ヘッダーなし・Shift_JIS・改行CRLF。列の並びは `yayoi_import/journal.py` の
`COLUMNS` を参照してください。

複合仕訳は同一伝票No.の連続行として書き出し、片側を諸口にしています。
**最初の取り込みだけは少数行で試して、弥生側の取り込み結果を確認してください。**
列の並びや税区分の表記は弥生のバージョンで差があり得ます。

## 関与先データの取り扱い

このリポジトリは公開されています。関与先の実データ（通帳CSV・エクセル・出力CSV）は
`.gitignore` で除外してあり、コミットされません。`clients/` 配下に置いてください。
`clients/_example/` だけが匿名のひな形として追跡対象です。
